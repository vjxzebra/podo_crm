# Podoria CRM — дизайн MVP

Чистий інтерактивний прототип CRM для одного подологічного кабінету.

## Відкрити дизайн

Відкрийте `index.html` у браузері. Для швидкого перегляду конкретної ролі використовуйте:

- `index.html?role=podologist#overview` — подолог;
- `index.html?role=reception#overview` — ресепшн;
- `index.html?role=admin#overview` — адмін / власник.

## Структура

```text
index.html          — усі екрани й модальні стани прототипу
assets/app.js       — інтерактивність і демонстраційна логіка
assets/*.css        — базові, модульні й адаптивні стилі
SPECIFICATION.md    — повне функціональне технічне завдання
```
